# Online Boutique – EKS Live Demo Link

## Purpose (for the examiner)

This page is intentionally a **single source of truth** for the live demo URL.

If anything breaks, restarts, or the public endpoint changes (for example after recreating the AWS load balancer), **only the URL on this page will be updated**. Please use this page to get the latest working link.

This is done so the report/documentation can remain unchanged, while the live endpoint can still be refreshed when needed.

This deployment runs the Online Boutique application on **AWS EKS**, including the new **Order Tracking** microservice.

The application is exposed publicly via a Kubernetes `Service` named `frontend-external` of type `LoadBalancer`.
